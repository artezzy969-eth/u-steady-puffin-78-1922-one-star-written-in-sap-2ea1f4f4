A program that writes one text line to `/output/entry.txt`: a one-line 1-star
review in the voice of a houseplant reviewing its human owner — a grievance
and a reason for the single star, in under 280 characters.

Run it with:

```sh
python3 main.py
```

It writes the review to `/output/entry.txt` using only the Python standard
library — no third-party imports, no network access.
